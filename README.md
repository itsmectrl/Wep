# Weechy Official Website

This folder contains the complete Weechy website.

## Finished Website Files (Ready to View or Deploy)
The compiled, ready-to-use static website files are located in the `dist` folder:
- `dist/index.html` — The main homepage with the interactive audio player, 400% loudness booster, synchronized lyrics, and download links.
- `dist/termsOfService.html` — The official Terms of Service page.
- `dist/privacyPolicy.html` — The privacy policy page.
- `dist/openSource.html` — The open source licenses and credits page.
- `dist/assets/` — The bundled stylesheets, fonts, and scripts that power the website.

You can double-click `dist/index.html` in any web browser or upload the contents of `dist` directly to any web host.

## Source Files (For Development)
- `src/` — All React components and style sheets.
  - `src/components/Header.jsx` — Navigation bar and mobile menu.
  - `src/components/Hero.jsx` — Hero section and interactive phone music player demo.
  - `src/components/PowerfulFeatures.jsx` — Feature cards and visual player showcase.
  - `src/components/GreatSound.jsx` — 400% volume boost slider and 5-band equalizer.
  - `src/components/BeautifulInterface.jsx` — Dynamic album artwork color palette engine.
  - `src/components/AddYourMusic.jsx` — Music library and folder browser tabs.
  - `src/components/MoreFeatures.jsx` — Speed changer, sleep timer, and backup features.
  - `src/components/CreatorVideos.jsx` — Community and creator video showcase.
  - `src/components/Reviews.jsx` — User ratings and audiophile testimonials.
  - `src/components/TechnicalArchitecture.jsx` — Synchronized lyrics and gesture arbitration details.
  - `src/components/DownloadHub.jsx` — Version 4.1 APK release download cards.
  - `src/components/FAQ.jsx` — Frequently asked questions.
  - `src/components/Footer.jsx` — Footer links and language selector.
- `package.json` — Build configuration and project dependencies.
- `vite.config.js` — Vite build configuration.
